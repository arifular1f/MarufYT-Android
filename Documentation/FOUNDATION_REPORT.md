Gradle distribution/dependencies are cached under the user's .gradle directory. A debug key is generated by Android tooling outside the repository. Environment variables were set only for build processes, not changed globally.

To reuse these tools in a new PowerShell session from the repository root:

```powershell
$marufTools = Join-Path $env:LOCALAPPDATA 'MarufYT-BuildTools'
$env:JAVA_HOME = (Get-ChildItem "$marufTools/jdk" -Directory | Select-Object -First 1).FullName
$env:ANDROID_HOME = "$marufTools/sdk"
$env:PATH = "$env:JAVA_HOME/bin;$env:ANDROID_HOME/platform-tools;$env:PATH"
.\gradlew.bat test assembleDebug --stacktrace
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
